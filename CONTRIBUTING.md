# Contributing

Thanks for helping make tiny on-device language models easier to explore.
Beginner questions, documentation fixes, verified board reports, memory
measurements, and code improvements are all welcome.

When reporting a problem, please include:

- exact board name;
- ESP32 Arduino core version;
- Arduino Tools settings;
- complete startup output from Serial Monitor;
- whether PSRAM is present and enabled;
- the smallest prompt that reproduces the issue.

Please keep claims precise: this project is a TinyStories text generator, not a
general-purpose assistant. New code derived from another project must retain
the applicable copyright and license notices.
